# REVERT — low-frequency chroma residual

One implementation attempt. The separate residual gives no convincing second visible win and weakens genuine soft colour. Candidate 1 remains exactly frozen; all nine production-source hashes match the pre-investigation baseline, the temporary diagnostics are removed, and the restored build passes. No new physical captures or diagnostic APK installation. No KEEP, hence no new single-frame device gate.

The broad component is already present at the immutable post-demosaic boundary, before fine cleanup. In B1 Hybrid dark-flat 1, characterised linear chroma spread at 32 px is 0.000411 before the fused fine/colour pass and 0.000396 after; at 64 px, 0.000195 and 0.000192. Dark-flat residual correlations between B frames range from −0.0384 to +0.0477. Row/column variance ratios of 0.90–1.59 do not establish an isolated persistent banding source. These observations locate the component before fine cleanup; they do not uniquely assign it to sensor, black level, LSC or reconstruction.

Attempt 1 uses a separate 8×8 scale representation in signed post-WB/CCM linear RGB. The existing physical covariance and spatial sigma field whiten chroma; a compact 7×7 neighbourhood supplies a local affine baseline. Covariance eigen-energy, signal, luma structure and chromatic gradient coherence gate its residual. It has no neutral-colour target. A bilinear Y=0 correction returns to full-resolution RGB before unchanged tone processing. The 5×5 estimator, demosaic, WB/CCM authority, luma processing and tone remain untouched.

This is an isolated host-reference implementation. Fields are estimated from exact diagnostic output and applied to fresh native replays. Application timings exclude Python field estimation and are not a production latency ranking. Diagnostic OLD matches all 54 saved Candidate 1 JPEGs exactly. Trial verification covers the same nine RAWs, all three actual demosaic paths without fallback, and two bitexact renders each.

LF spread is the pooled standard deviation of block-averaged JPEG R−G/B−G, including real scene variation. Ranges cover both fixed B flat ROIs, B1/B2/B3 and all three modes. These are proxies, not isolated sensor-noise measurements. The soft-colour test is a noiseless 2D Gaussian chroma variation, sigma 40 native pixels, in a dark linear field; its peak attenuation independently violates colour-structure protection.
