# SF2 phase 4 — Guided Fine Luma (debug-gated)

**Delivery status:** CPU+Vulkan code complete; synthetic native validation and GLSL→SPIR-V compilation verified in CI. Android APK build and HONOR Magic 8 Pro device quality/performance/parity validation **pending**. Guided Fine is **not promoted** to default production denoising.

## Where it operates

- Input: the existing immutable full-resolution demosaiced camera-linear RGB.
- Physical model: the existing post-demosaic residual Y variance/confidence, propagated from effective physical sensor S/O. A previously resolved fusion-variance factor is reused once, not estimated again.
- Spatial noise: the existing *relative* physical sigma shape; no additional LSC or exposure gain is applied.
- Guided output: a **single additive scalar luma correction** distributed equally to R, G and B **after the existing chroma denoiser**. Existing post-chroma opponent differences remain unchanged.
- The CPU oracle (`SingleFrameGuidedLuma.h`) and included Vulkan shader (`physical_luma_denoise.glsl`) use the same local 3×3 signal-aware weights and variance-based shrinkage, with a bounded structure-evidence gate.
- The old legacy algorithm body is retained in `physicalLegacyLumaDenoise` and protected by exact source comparison.

This implementation is deliberately **fine-level only**. It does not modify coarse/DC bands, sharpening, demosaic, RAW finalization, fusion, AWB, CCM or tone mapping. New fine authority is limited to a maximum of 0.78 of the local regression residual before the structure gate; this bound is a heuristic, not a validated optimal denoising strength.

The current `SingleFrameNoiseContext` records fixed-kernel spatial correlation *proxies*, but does not establish actual total post-demosaic noise correlation, especially for AMaZE/Auto Hybrid. Guided Fine presently consumes the propagated scalar noise variance/confidence, **not an invented spatial rho**. Real adaptive-route quality remains to be validated.

## Runtime selection (debug build only)

| Stage | Value | Behavior |
|---|---:|---|
| OFF / normal product baseline | 0 | Chroma-only; Guided Fine inactive |
| LEGACY_REFERENCE | 1 | Prior luma reference, debug only |
| GUIDED_V2 | 2 | New Guided Fine, debug only |

Stage is selected explicitly via the existing debug benchmark receiver's `physicalLumaStage` integer extra; the JNI setter is a no-op with `NDEBUG` defined, and the atomic selected stage defaults to OFF. The request to the Vulkan colour stage includes the selected stage; the mode-3 shader reads it from previously unused `residualStride` bits 2..4. **No push-constant ABI, framebuffer or full-frame resident readback is added.** CPU fallback selects the corresponding CPU oracle.

The existing `physicalLuma` boolean debug control remains backward compatible: false → OFF, true → LEGACY_REFERENCE.

## Same-RAW debug quality comparison

When the existing debug-only `physicalLumaAbDirectory` is enabled, the same immutable RAW master and same metadata are rendered three times into a timestamped folder:

- `off.jpg` / `off.txt`: chroma-only reference.
- `on.jpg` / `on.txt`: frozen legacy luma reference.
- `guided.jpg` / `guided.txt`: Guided Fine candidate.

Each text file stores capture diagnostics from that render. All three use the same RAW input; this does not imply equivalence of GPU timing or sensor ground truth. This triple render is **not enabled in normal capture**. A production capture does not create extra image passes because of this debug feature.

After the debug comparison, the stage is restored to OFF in `finally`. The existing RAW-master integrity fingerprint remains checked.

## Verified by repository CI

- `SingleFrameGuidedLumaTest.cpp`: synthetic flat-field noise reduction, finite output, exact constant bypass, additive RGB/opponent preservation, narrow-line and step-edge retention, exact bypass for invalid noise/shapes, and fine-only authority.
- All prior phase-0–3 native tests and phase-4 source guards, including the exact previous luma kernel body, frozen chroma, and absence of any default Guided route.
- GLSL shader `spectra_demosaic_resident.comp` compiled with `glslc` into nonempty Vulkan 1.1 SPIR-V, including the new Guided Fine include.

**Not yet verified:** Android APK full Gradle/NDK packaging, device GPU execution versus CPU oracle numerical parity, actual hair/grass/textile/text retention, high-ISO JPEG comparisons, mobile latency/temperature/memory. Native synthetic tests establish **limited functional correctness**, not photographic acceptability.
